## 🎯 Sobre o projeto

A Calculadora Simples é uma aplicação gráfica que permite realizar operações matemáticas básicas a partir de dois números informados pelo usuário.

O projeto foi desenvolvido para praticar conceitos fundamentais de Python e compreender o funcionamento de interfaces gráficas com Tkinter.

## ⚙️ Funcionalidades

- ➕ Adição de dois números.
- ➖ Subtração de dois números.
- ✖️ Multiplicação de dois números.
- ➗ Divisão de dois números.
- 🔢 Entrada de números inteiros e decimais.
- ⚠️ Tratamento de entradas inválidas.
- 🛡️ Tratamento de divisão por zero.
- 🖥️ Interface gráfica com campos de entrada, botões e exibição do resultado.
- 📐 Interface centralizada automaticamente na janela.

## 🛠️ Tecnologias e conceitos utilizados

- **Python:** lógica de programação, variáveis, funções, condicionais e tratamento de exceções.
- **Tkinter:** criação de interfaces gráficas.
- **Entry, Label e Button:** componentes para entrada de dados, exibição de informações e interação.
- **Grid, Pack e Place:** gerenciamento e posicionamento de componentes na interface.
- **Lambda:** passagem de argumentos para funções acionadas pelos botões.
- **Try/Except:** tratamento de erros durante a execução das operações.
- **Git e GitHub:** versionamento e compartilhamento do projeto.

## ▶️ Como executar o projeto

**Pré-requisitos:**
- Python 3 instalado.
- Tkinter disponível na instalação do Python.

**Passos:**

1. Clone este repositório:

   ```bash
   git clone https://github.com/ViniciusRdeOliveira/calculadora_python.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd calculadora_python
   ```

3. Execute o arquivo Python da calculadora:

   ```bash
   python calculadora.py
   ```

   *Observação: substitua `calculadora.py` pelo nome real do arquivo, caso seja diferente.*
